# Changelog / 更新记录

## 1.0.0 — 2026-11-07

- Read-only diagnostics and narrow, confirmed-false-only repair for the macOS Continuity Camera host switch.
- Protected backup, integrity validation, transaction lock, targeted rollback, and failure recovery.
- Management-policy and multiuser-session guards; no automatic logout, reboot, or protected-service manipulation.
- English/Chinese documentation and CLI messages, Finder launcher, isolated regression tests, and macOS CI.

- 只读检测及仅针对明确布尔值 false 的主机开关修复。
- 受保护备份、完整性校验、事务锁、单项回滚及失败恢复。
- 管理策略和多用户会话检查；不自动注销、重启或操作受保护服务。
- 中英文文档及交互消息、Finder 启动器、隔离回归测试和 macOS CI。
