# Security / 安全问题

This tool runs a narrowly scoped preference mutation with administrator privileges. See [the safety model](docs/SAFETY.md) before use. The current `1.x` release line receives safety fixes; there is no guaranteed response time.

For a suspected vulnerability, use GitHub's **Security → Report a vulnerability** if private reporting is available. Otherwise open a minimal issue requesting a private reporting channel, without exploit instructions or sensitive material. Never include tokens, full preference backups, raw device logs, or personal identifiers in a public report.

本工具使用管理员权限修改范围明确的单项偏好，使用前请阅读[安全模型](docs/SAFETY.zh-CN.md)。目前维护 `1.x` 版本的安全修复，不承诺固定响应时间。

如发现漏洞，优先使用 GitHub 的 **Security → Report a vulnerability**（若已启用私密报告）；否则仅提交请求私密联系渠道的简短 Issue，不公开利用细节或敏感信息。请勿上传令牌、完整偏好备份、原始设备日志或个人标识。
